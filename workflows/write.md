# Write for X

## Format

| Content | Format |
| --- | --- |
| A quick reaction, feeling, or opinion | X Post |
| A few connected points, steps, or a short story | Thread |
| A tutorial, hands-on test, process, comparison, or full analysis | X Article |

If I pick a format, use it. Check the X Premium setting in [profile.md](../context/profile.md): without Premium, keep each post to 280 characters, turn longer content into a Thread, and don't write long posts or Articles.

## Before writing

* Read [profile.md](../context/profile.md).
* Read related past content in [x_posts.md](../output/x_posts.md) and [x_articles/](../output/x_articles/). Learn the word choice, sentence length, openings, and formatting. Check what I've said before so I don't contradict myself, and build on it where you can.

## Posts and Threads

Write the draft directly. No outline needed unless I ask.

## Articles

Start with an outline that covers four things:

* **Angle:** How I see this topic, based on the "Posting angle" in my profile.
* **Key message:** The one line readers should remember.
* **Support:** The facts, my experiences, or data you'll use, with sources. If I haven't given an experience, build it from public facts and my views. Don't ask me for one.
* **Flow:** What each section covers, in order.

Write the full draft only after I approve.

## Writing

* Follow the writing style in [profile.md](../context/profile.md) and the rules in [AGENTS.md](../AGENTS.md#writing-for-me). Give me one version first, and alternatives only when I ask.
* If a Post needs a link or extra context, put it in a separate reply.

## Saving

| Content | Location and format |
| --- | --- |
| X Post or Thread | Top of [x_posts.md](../output/x_posts.md) |
| X Article | `output/x_articles/YYYY-MM-DD-<slug>.md`, with only the title and body, including any links the body cites |

Post format:

```markdown
## YYYY-MM-DD · Topic

Post text

**Quoting:** Link to the quoted post (if it's a quote post)

**Reply:** Reply text (if any)
```

For a Thread, number each post, with a blank line between them:

```markdown
## YYYY-MM-DD · Topic

1/ First post

2/ Second post
```

Save as soon as it's written, without asking. When editing, save changes in place.
